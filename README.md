# Online-store-database-simulation.
A project that simulates the database of an online store using SQL on MySQL 

this project is a MySQL database that simulates the backend of a small online store selling sweets, accessories, and stationery. This includes eight connected tables: customers, addresses, categories, products, orders, order items, payments, and reviews. It uses constraints such as CHECK, UNIQUE, and foreign keys to maintain data accuracy and consistency. Sample data is also included for testing. The database requires MySQL 8.0 

Overall, this project focuses on relational database design, with future plans to add features such as a shopping cart and discount codes.
